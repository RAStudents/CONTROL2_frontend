# Разработка веб-сервиса коллективной разметки, инспекции и валидации датасетов компьютерного зрения (рабочее название CONTROL)

## Цель
Создание универсальной веб-платформы (серверной части и фронтенда) для централизованного управления парком Edge-устройств, бизнес-привязками и формирования аналитической отчетности по инцидентам и статусам для различных отраслевых задач (логистика, HoReCa, производство, медицина).

## Результат (продукт)
Веб-приложение с клиент-серверной архитектурой, обеспечивающее реестр устройств и динамических справочников «Привязок», прием телеметрии и медиа-файлов через API, ролевую модель доступа и модуль построения отчетов (по Статусам, Событиям, План/Факт) с интерактивной визуализацией и экспортом данных.

## Критерии приемки

### Технические критерии:
* Универсальная схема данных и конфигурируемость: Поддержка динамических справочников «Привязок» (ТС, Кухни, Кабинеты) и «Статусов» (Код 0, Код 1 и т.д.) через конфигурационные файлы/БД без изменения кода приложения под конкретный продукт (Водитель, HoReCa, Мед и др.).
* API-шлюз для телеметрии и интеграций: Реализация защищенных эндпоинтов для приема событий и медиа-файлов от Edge-устройств, а также API для обмена данными со сторонними системами (например, SAP WMS для получения плановых заданий).
* Архитектура хранения и безопасности: Использование реляционной СУБД с поддержкой Multi-tenancy (изоляция данных компаний) и ролевой модели (Администратор поставщика, Администратор компании, Старший оператор, Оператор).
* Документация: OpenAPI/Swagger спецификация API, Docker Compose для развертывания.

### Функциональные критерии:
* Реестр Устройств и Привязок: Табличное представление устройств (UIN, IP, Сеть, Статус) с возможностью массового импорта/экспорта (CSV), проверки статуса подключения и назначения «Привязок» через выпадающие справочники.
* Модуль Отчетности (Статусы, События, План/Факт): Построение таблиц и графиков по временным интервалам. Кликабельные факты событий, открывающие модальное окно с фото- или видео-подтверждением инцидента. Фильтрация по Привязкам, Устройствам и датам.
* Управление доступом и Компаниями: Интерфейс администрирования для создания компаний-клиентов, назначения администраторов и управления правами пользователей внутри компании.
* Медиа-просмотрщик: Встроенный HTML5-плеер для воспроизведения видеофрагментов инцидентов, полученных с Edge-устройств, с синхронизацией по таймкодам.

## Описание проекта
Проект посвящен разработке инженерного B2B-инструмента для управления распределенными системами компьютерного зрения (Edge AI). Команда реализует масштабируемый бэкенд и универсальный фронтенд-интерфейс, превращающий сырой поток событий с периферийных устройств в структурированную бизнес-аналитику. Ключевая особенность — единая кодовая база, которая адаптируется под разные отраслевые задачи (от контроля водителя до мониторинга производительности на кухне) исключительно за счет смены конфигурационных справочников «Привязок» и «Статусов», что исключает необходимость разработки отдельных интерфейсов под каждого заказчика.
